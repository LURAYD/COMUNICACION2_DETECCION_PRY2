# Prueba adaptativa acotada, fijada antes de evaluar

Objetivo falsable: determinar si una decisión desde256 IQ puede mejorar utilidad frente a modelos fijos. Se usa CNN original como referencia avanzada ya fijada, SVM256 y SVM512 congelados. No se vuelve a comparar arquitectura/augmentation para elegir rama.

Dataset nuevo semilla2026110613,2400 señales por split. Train ajusta un único RF multioutput de100 árboles, profundidad5 y mínimo30 muestras/hoja, a corrección contrafactual de tres acciones menos costo. Val se divide de modo determinista dentro de cada clase/SNR: primeras25 realizaciones para calibración,25 restantes para seleccionar umbrales. No hay padres compartidos. Test/shift nuevos se reservan mediante hashes antes de desarrollar el selector; se abren solo tras guardar selector/umbrales y hashes. No se usan los720 padres del diagnóstico ni los holdouts anteriores.

Ruta adaptativa: extraer65 características de256 IQ y ejecutar SVM256; se añaden6 scores SVM al vector del selector. Ninguna entrada contiene etiqueta, SNR/CFO/canal verdaderos, muestras256:512 ni predicciones CNN/SVM512 aún no ejecutadas. El objetivo contrafactual offline sí usa etiquetas de train. La API observable rechaza matrices con longitud512. Si termina a0 reutiliza etiqueta SVM; a1 paga32ms adicionales de adquisición y SVM512; a2 paga CNN256 adicional. La CNN sola se evalúa como baseline legítimo sin cobrar SVM.

Función de ingeniería fijada: utilidad=accuracy−0,002×(adquisición virtual+CPU en ms). El coeficiente no se elige por test;32ms adicionales cuestan0,064 de utilidad. El RF aproxima utilidad esperada, no una probabilidad calibrada. Un candidato RF, una semilla; sin búsqueda masiva.

Baselines: siempre SVM256/SVM512/CNN; umbral de confianza SVM calibrada que conserva a0 o pide a1; regla de planitud espectral que usa a2 cuando flatness supera umbral y a1 en otro caso. La planitud no se presenta como SNR: no hay referencia de ruido que permita estimarla de forma general. La confianza calibra P(SVM256 acierta) mediante regresión logística del margen entre dos scores mayores usando solo val_cal; no cambia su etiqueta. Umbral de confianza: rejilla prefijada0…1 y1,01. Umbral de flatness: cuantiles de train y extremos. Ambos se eligen por utilidad en val_select. Esto no implementa abstención ni probabilidad multicategoría calibrada.

Costos de desarrollo: bases medidas batch1 en96 ventanas val_cal y3 repeticiones; selección de políticas incluye medición completa de rutas en val_select. Test: se ejecuta realmente cada ruta completa una vez por padre, con orden de políticas aleatorio prefijado, un hilo CPU, calentamiento y modelo cargado. Incluye extracción, SVM previo, calibrador/RF cuando corresponda y rama elegida. Latencia de pared se suma a N/fs virtual; no se duerme para simular adquisición. GPU no interviene en estas latencias: las bases permanecen congeladas y la CNN es suficientemente pequeña para CPU. No se incluyen detector/PSD/estimador ajenos a este clasificador condicional.

Se congela también el mejor baseline fijo por utilidad val. Comparaciones primarias de las políticas contra ese baseline en test/shift: diferencia pareada accuracy, tiempo y utilidad,10000 réplicas estratificadas clase/SNR. Intervalos condicionan a modelos/medición fija y no incluyen variación entre entrenamientos/sesiones de carga. Se reportan acciones por SNR, calibration Brier/NLL/ECE10 y cobertura100% sin abstención. No se ajustará ningún componente por test.

Antecedentes ya consultados directamente: BEACON p.PDF12, recuperabilidad y vector completo de scores frente a confianza escalar; Fewer-Sample p.PDF2, adquisición N/fs separada de cálculo y supuesto de sincronización previa. Se toma la pregunta de beneficio, no sus arquitecturas ni porcentajes; no se afirma novedad.

Artefactos/reanudación: `results/adaptive/reservation.json`, cachés offline por split, `policy.joblib`, `selection_frozen.json`, NPZ de rutas por régimen y estado. GNU Radio y ADC pospuestos.
